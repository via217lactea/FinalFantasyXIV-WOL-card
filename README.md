# FF14 빛의 전사 명함 메이커

파이널판타지14 팬페스티벌에서 서로 나누는 **빛의 전사 명함**(ヒカセン名刺)을 만드는 도구.
캐릭터 사진과 진행도·플레이 성향·접속 시간대를 명함 한 장에 담아, 화면용 PNG와 인쇄용
CMYK PDF로 저장한다. 2027년 3월 팬페스티벌 서울을 겨냥한 한국어판이다.

배포 주소: <https://finalfantasyxiv-wol-card.pages.dev>

## 구조

빌드가 없다. 저장소의 `index.html` 한 파일이 앱 전체다. HTML·CSS·JS와 직업 아이콘
(data URI)이 모두 이 안에 들어 있다.

| 외부 의존 | 용도 | 비고 |
|---|---|---|
| `qrcode-generator@1.4.4` (jsDelivr) | QR 코드 모듈 계산 | 버전 고정. UTF-8 인코더로 교체해서 쓴다 |
| Google Fonts | 한글·라틴 글꼴 | 전부 SIL OFL |

서버가 없으므로 올린 사진과 입력 내용은 브라우저 밖으로 나가지 않는다.

## 렌더링

명함은 DOM이 아니라 **캔버스에 직접 그린다.** 미리보기와 저장 이미지가 같은 함수
(`drawCard`)를 거치므로 저장 결과가 미리보기와 어긋날 수 없다. DOM 캡처 방식에서 겪던
글꼴 누락·외부 자산 누락 문제가 구조적으로 생기지 않는다.

좌표는 논리 단위다. 명함의 긴 변이 항상 `1000`이고, 출력 해상도에 맞춰 배율만 바꾼다.

| 규격 | 가로 명함 | 세로 명함 |
|---|---|---|
| `kr` 90×50mm | 1000 × 555.6 | 555.6 × 1000 |
| `jp` 91×55mm | 1000 × 604.4 | 604.4 × 1000 |

세로 명함은 가로 레이아웃을 돌린 것이 아니라 세로 지면용 레이아웃을 따로 쓴다.

### 앞면

사진 배치는 두 가지다.

| 값 | 성격 |
|---|---|
| `frame` | 룩북 지면. 사진이 한쪽을 차지하고, 글자 쪽 가장자리를 종이에 녹인다(`fade`) |
| `full` | 사진이 앞면 전체. 글자 쪽에만 진하게 막(`scrim`)을 깔고 글자색을 막에 맞춘다 |

제목·부제목은 앞면 왼쪽 위와 뒷면 오른쪽 위에 들어가며 저장 파일 이름이 된다.
세로 스파인 문구는 비워 두면 그리지 않는다.

### 뒷면 자동 배치

뒷면은 채운 항목만 블록으로 만들어 단(가로 3단, 세로 2단)에 순서대로 쌓는다.

```
msq → levels → matrix → raid → time → styles → tags → seeking → social → intro → qr
```

넘치면 밀도 `d`를 1.0에서 0.04씩 줄이며 다시 배치한다. 0.6까지 줄여도 넘치면 들어가지
않는 블록을 빼고, 편집 화면에 경고를 띄운다. 앞면도 같은 방식으로 맞춘다.

QR 코드는 밀도와 무관하게 논리 단위 100(약 9mm) 아래로 줄이지 않는다. 인쇄물에서
휴대폰으로 읽히지 않기 때문이다. 그래서 QR을 추가할 때는 한 개가 더 들어간 상태를
미리 배치해 보고(`backFitsWith`), 안 들어가면 추가를 막는다. 최대 6개.

### 그리는 순서

```
종이색 → 레이어(글자 아래) → 앞면/뒷면 내용 → 레이어(글자 위) → 종이 질감 → 재단선
```

종이 질감을 맨 마지막에 덮는다. 그래야 흐리게 녹인 사진 가장자리와 단색 면이 종이와
같은 결을 가진다. 질감을 먼저 깔면 덮인 부분만 매끈하게 떠 보인다.

## 색

밝게/어둡게 두 테마에, 선택적으로 **시그니처 컬러**를 얹는다.

시그니처 컬러는 기준색 하나로 다섯 단계 팔레트를 만든다. OKLCH 공간에서 기준색의
명도에 가장 가까운 칸에 기준색을 두고, 나머지 칸은 종이 쪽(0.965)과 잉크 쪽(0.22)으로
명도를 고르게 벌린다. 채도는 양 끝으로 갈수록 줄이고, sRGB 밖으로 나가면 채도를 깎아
되돌린다. **AI 호출 없이 페이지 안에서 계산한다.**

- `새로 섞기`는 시드만 바꿔 색조 흐름과 채도 배율을 다시 뽑는다.
- 사용자가 코드를 고치거나 색을 고른 칸은 자동으로 잠겨 섞기에서 살아남는다.
- 명함에 쓸 때는 다섯 색을 명도순으로 다시 정렬한다. 가장 밝은 색이 종이, 가장 어두운
  색이 잉크다(어둡게 테마는 반대). 두 색의 대비가 4.5:1 미만이면 경고한다.

## 내보내기

| 형식 | 색 | 쓰임 |
|---|---|---|
| PNG | RGB | 화면 공유, SNS. RGB 입고를 받는 인쇄소 |
| 인쇄용 PDF | DeviceCMYK | 인쇄소 입고. 앞뒷면이면 1쪽 앞면, 2쪽 뒷면 |

- 해상도는 300 / 600 dpi. 90×50mm 600 dpi 한 면이 2,126×1,181px다.
- 재단 여백(도련)은 0~3mm. 종이색·질감·전면 사진·막은 여백까지 이어 그린다(`BLEED`).
  국내 명함 인쇄소의 90×50 작업 크기는 보통 92×52mm다.
- PDF는 외부 라이브러리 없이 직접 쓴다. 이미지는 `CompressionStream('deflate')`로 압축한
  `/FlateDecode` 스트림이고, 쪽마다 `TrimBox`와 `BleedBox`를 기록한다.

### CMYK 변환

브라우저에는 ICC 프로파일이 없으므로 **근사 변환**이다. 회색 성분을 전부 K로 보내는
GCR 방식이라 무채색은 먹 1도로 찍힌다. 작은 글자가 판 어긋남으로 번지지 않고, 잉크
총량이 300%를 넘지 않는다. 형광빛 파랑·초록은 인쇄에서 탁해질 수 있으므로 첫 주문은
시험 인쇄를 권한다.

### 다운로드

`window.claude.use('downloads')`가 있으면(claude.ai 미리보기) 그것으로 저장하고,
없으면(일반 웹) `<a download>`로 내려받는다. PNG가 안 받아지는 환경을 위해 만든 이미지를
화면에도 띄운다.

## 직업 아이콘

게임 클라이언트의 퀘스트용 직업 문양을 단색 마스크로 바꿔 쓴다. 명함에서는 잉크 색으로
칠한다.

| 범위 | 내용 |
|---|---|
| `062401`–`062422` | 전투 직업 22개. ClassJob 순서(나이트 19 → 픽토맨서 42)에서 클래스를 뺀 순서 |
| `062310`–`062320` | 제작·채집 11개 (목수 → 어부) |
| `062423` | 마수조련사. XIVAPI의 `_hr1`(64px)에서 받음 |

원본은 금색 문양에 주황 후광이 둘러진 32px 투명 PNG다. 불투명하고 밝은 부분만 남겨
후광을 걷어 내고(`alpha`·명도 문턱), 64px 흰색 마스크로 저장했다.

### 알려진 함정

- 직업 아이콘 번호는 `062000 + ClassJob ID` 규칙을 따르지 않는 것이 있다. 마수조련사는
  ClassJob 43이지만 `062043`·`062143`이 존재하지 않는다. 실제 번호는 `JournalGenre`
  시트의 직업 퀘스트 분류 아이콘(`62423`)에서 찾았다.
- 한섭 데이터에 번호가 있어도 SaintCoinach `ui 62423 62423`은 `0 images processed`를
  낸다. 이 경우 XIVAPI asset 엔드포인트에서 받는다.
- `0620xx`·`0621xx`는 테두리 컬러 버전, `0628xx`는 밝은 타일 배경의 장비 세트 아이콘이라
  단색 마스크로 쓸 수 없다. `0628xx`는 암흑기사·건브레이커도 빠져 있다.

## 글꼴

| 구분 | 선택지 |
|---|---|
| 제목·닉네임·칭호 | 기본(보도니 + 고운바탕), 고운바탕, 나눔명조, 본명조, 함렛, 송명, 본고딕, 나눔고딕, 고운돋움, 도현, 주아, 검은고딕, 개구, 나눔손글씨 펜, 오르빗 |
| 본문 | IBM Plex Sans KR(기본), 본고딕, 나눔고딕, 고딕 A1, 고운돋움, 본명조, 나눔명조, 고운바탕 |

영문 장식(섹션 영문 부제, 스파인, 메인 스토리 버전 숫자)은 어떤 조합에서도 Bodoni Moda다.
굵기가 하나뿐인 글꼴은 가짜 굵게를 피하려고 가장 가까운 실제 굵기로 그린다.

캔버스는 CSS처럼 글꼴을 알아서 받지 않는다. 한글 웹폰트는 `unicode-range` 조각으로
나뉘어 있으므로, 그리기 전에 실제로 쓸 글자를 넣어 `document.fonts.load(spec, text)`를
부르고, 새 조각이 들어오면 다시 그린다. 글꼴×글자 조합별로 이미 받은 것을 기억한다.

## 입력 항목

| 탭 | 항목 |
|---|---|
| 앞면 | 사진(위치·확대·진하기·경계 흐림·배치), 제목·부제목·스파인, 닉네임(인게임과 다름 표시), 서버, 칭호, 종족·성별, 새싹·멘토, 메인 직업(직군 전체 선택 가능) |
| 진행도 | 메인 스토리(2.0 – 7.5, 진행 중/완료), 직업 레벨 34개, 콘텐츠×역할, 레이드 진행도, 클리어한 절 7종 |
| 플레이 | 플레이 성향 6, 즐기는 콘텐츠 25(전투·생활·PvP·꾸미기·미니게임), 현재 상태 7, 교류, 접속 시간대(평일·주말 24칸) |
| 소개·링크 | 자기소개 200자, QR 코드 최대 6개 |
| 꾸미기 | 글꼴, 이미지 레이어 최대 12개(면·글자 위/아래·크기·회전·투명도) |

- 서버는 한섭 5개와 글섭 11개 데이터센터, 직접 입력.
- 리미티드 잡 만렙은 청마도사 80, 마수조련사 50으로 따로 둔다.
- 종족의 `메타몽`은 환상약으로 종족을 자주 바꾸는 사람을 위한 값이다.
- 레이드 진행도와 절 이름은 편집 화면의 선택지 문구가 명함에 그대로 찍힌다.

## 저장

`localStorage`의 `wol-card-v1` 한 키에 상태 전체를 JSON으로 둔다(0.5초 디바운스).

- 사진은 긴 변 2,600px, 레이어 이미지는 1,000px로 줄여 담는다.
- 용량 초과 시 사진과 큰 레이어를 빼고 다시 저장한다.
- 이전 버전 저장분은 읽을 때 옮긴다. 단일 QR(`qrUrl`) → `qrs[]`, 단일 플레이 스타일
  목록 → `styles` / `tags` 분리, 한섭 전용 서버 값.

## 배포

Cloudflare Pages, `main` 브랜치에 커밋하면 자동 배포된다.

| 설정 | 값 |
|---|---|
| Framework preset | None |
| Build command | (비움) |
| Build output directory | (비움) |

파일 이름은 반드시 `index.html`이어야 한다. 다른 이름이면 배포는 성공해도 루트 주소가
404를 낸다.

## 알려진 함정 (앱)

- 샌드박스 iframe(claude.ai 미리보기)은 `window.confirm`을 막는다. 초기화 같은 파괴적
  동작은 화면 안 확인 버튼으로 처리한다.
- 접속 시간대 눈금 줄은 첫 칸이 라벨 열이다. 모든 `span`에 `grid-column: span 6`을 주면
  빈 첫 칸도 6시간 폭을 차지해 눈금이 한 구간씩 밀린다.
- 레이어 끌기와 사진 끌기가 같은 캔버스를 쓴다. 맨 위 레이어부터 회전을 풀어 적중
  판정하고, 아무 레이어에도 안 맞을 때만 사진을 움직인다.
